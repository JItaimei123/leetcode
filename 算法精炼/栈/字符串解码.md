给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a` 或 `2[4]` 的输入。

测试用例保证输出的长度不会超过 `105`。

示例 1：

```C++
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

思路：建立两个栈 一个用于存放数字→数字栈 一个用于存放字符串→字符串栈

以`2[a2[b3[bc]]]`举例，可以看到这里有`数字` `[` `]` `字符` 这四种数据类型，其中`[`和`]`作为触发条件，分别将数字和字符放入对应的栈中。

```C++
class Solution {
public:
    string decodeString(string s)
    {
        // 前置工作，先建两个栈
        stack<int> numstk;
        stack<string> strstk;
        // 累计当前数字和字符串
        int num = 0;
        string cur = "";
        // 遍历字符串
        for (int i = 0; i < s.size(); i++)
        {
            char c = s[i];
            // 1.遍历到数字，若有多位就累加起来
            if (isdigit(c))
            num = num * 10 + (c - '0');
            // 2.遍历到'[',把当前的cur和num入栈然后重置->重置可以保证优先合并里括号，并且将前面的存档在栈里
            else if (c == '[')
            {
                numstk.push(num);
                strstk.push(cur);
                num = 0;
                cur = "";
            }
            // 3.遍历到']',弹出数字栈的栈顶，与之前字符串拼接
            else if (c == ']')
            {
                int topn = numstk.top();
                numstk.pop();
                string tops = strstk.top();
                strstk.pop();

                // 将字符串tops拼接topn次
                for (int j = 0; j < topn; j++)
                tops += cur;
                cur = tops;
            }
            // 4.遍历到字符，直接追加到字符串中
            else  cur += c;
        }
        return cur;
    }
};
```
