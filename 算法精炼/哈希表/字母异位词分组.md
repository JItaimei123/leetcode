给定一个字符串数组 `strs`，将 变位词 组合在一起。 可以按任意顺序返回结果列表。

注意：若两个字符串中每个字符出现的次数都相同，则称它们互为变位词。

示例 1：

```C++
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

思路：用哈希表中key value可自定义的特征构建`<string,vector<string>>`,将每一个字符串根据ASCII码值先排序，比如`ate，ant，abt`，遍历排序后遍历每个字符串，符合条件的就加到哈希表中的字符串数组中

```C++
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) 
    {
        unordered_map<string,vector<string>> hash;
        //把所有字母的异位词分组
        for(auto s : strs)
        {
            string tmp = s;
            sort(tmp.begin(),tmp.end());
            hash[tmp].push_back(s);
        }
        //从哈希表中取出
        vector<vector<string>> ret;
        for(auto [x,y] : hash)
        {
            ret.push_back(y);
        }
        return ret;
    }
};
```

```C++
for (auto [x, y] : hash)
{
    ret.push_back(y);
}
```

等价于：

```C++
for (auto pair : hash)
{
    string x = pair.first;    // key
    vector<string> y = pair.second;  // value
    ret.push_back(y);
}
```

`[x, y]` 就是把 `pair.first` 和 `pair.second` 一次性解包出来。

普通写法要这样：

```C++
for (auto p : hash) {
    p.first   // key
    p.second  // value
}
```

结构化绑定让你跳过 `.first` 和 `.second`，直接给它们起名字：

```C++
for (auto [key, value] : hash) {
    key     // 直接用 key
    value   // 直接用 value
}
```

### 单独解析这一行

```C++
hash[tmp].push_back(s);
```

这里`hash[tmp]`是`vector<string>`类型，因为在定义哈希表的时候，就把 `value` 的类型设成了 `vector<string>`。

| 表达式 | 类型 | 有 push_back 吗 |
| --- | --- | --- |
| hash | unordered_map | ❌ 没有 |
| hash[tmp] | vector<string> | ✅ 有 |

所以必须先 `hash[tmp]` 取出 vector，再对它 `push_back`。

### 同时`hash[tmp]` 就是“放到哈希表中”的动作。

### 分情况看

情况 1：`tmp` 这个 key 不存在

```C++
hash["aet"].push_back("eat");
```

- `hash["aet"]` → key `"aet"` 不存在，自动创建 `hash["aet"] = []`

- `.push_back("eat")` → `hash["aet"] = ["eat"]`

哈希表里多了一条：`"aet" → ["eat"]`

情况 2：`tmp` 这个 key 已存在

```C++
hash["aet"].push_back("tea");
```

- `hash["aet"]` → key `"aet"` 已存在，返回 `["eat"]`

- `.push_back("tea")` → `hash["aet"] = ["eat", "tea"]`

哈希表里原来的组被更新了。
