基因序列可以表示为一条由 8 个字符组成的字符串，其中每个字符都是 `'A'`、`'C'`、`'G'` 和 `'T'` 之一。

假设我们需要调查从基因序列 `start` 变为 `end` 所发生的基因变化。一次基因变化就意味着这个基因序列中的一个字符发生了变化。

- 例如，`"AACCGGTT" --> "AACCGGTA"` 就是一次基因变化。

另有一个基因库 `bank` 记录了所有有效的基因变化，只有基因库中的基因才是有效的基因序列。（变化后的基因必须位于基因库 `bank` 中）

给你两个基因序列 `start` 和 `end`，以及一个基因库 `bank`，请你找出并返回能够使 `start` 变化为 `end` 所需的最少变化次数。如果无法完成此基因变化，返回 `-1`。

注意：起始基因序列 `start` 默认是有效的，但是它并不一定会出现在基因库中。

示例 1：

```C++
输入：start = "AACCGGTT", end = "AACCGGTA", bank = ["AACCGGTA"]
输出：1
```

示例 2：

```C++
输入：start = "AACCGGTT", end = "AAACGGTA", bank = ["AACCGGTA","AACCGCTA","AAACGGTA"]
输出：2
```

## 思路：

```C++
class Solution {
public:
    int minMutation(string startGene, string endGene, vector<string>& bank)
    {
        //把合法的基因存进哈希表中 当修改后的endGene在哈希表中就把这个基因从哈希表中删除并入队
        unordered_set<string> hash(bank.begin(),bank.end());
        if(!hash.count(endGene)) return -1;
        if(startGene == endGene) return 0;
        //开始bfs查找
        queue<string> q;
        q.push(startGene);
        //如果刚放进去的这个基因在bank中就移除
        hash.erase(startGene);
        int steps = 0;
        string genes = "ACGT";
        while(q.size())
        {
            int sz = q.size();
            //进入循环开始找
            steps++;
            //遍历每一层
            for(int i = 0;i<sz;i++)
            {
                //获取当前基因
                string curgene = q.front();
                q.pop();
                //依次修改当前字符串并查询是否在哈希表中
                for(int j = 0;j<8;j++)
                {
                    char orichar = curgene[j];
                    //修改当前字符,并判断是否在哈希表中
                    for(auto c : genes)
                    {
                        if(c == orichar) continue;
                        else curgene[j] = c;
                        //标记修改后的字符串
                        string nextgene = curgene;
                        //如果在哈希表中并符合题目条件 就返回 在哈希表但不符合题目条件就作为"中转"基因存到队列继续修改下一位
                        if(hash.count(nextgene))
                        {
                            //符合目标基因
                            if(endGene == nextgene) return steps;
                            //作为"中转"基因存到队列继续修改下一位
                            else
                            {
                                hash.erase(nextgene);
                                q.push(nextgene);
                            }
                        }
                    }
                    ////每对一位修改完就还原再修改下一位
                    curgene[j] = orichar;
                }
            }
        }
        return -1;
    }
};
```

BFS 的骨架永远不变：

1. `q.push(起点)` + 标记起点。

2. `while(q.size())` + `sz = q.size()` + `steps++`。

3. `for(遍历当前层)` ->获取当前层的队头→ `pop` -> `for(找邻居)` -> `判断合法/是否终点` -> `标记 + push`。
