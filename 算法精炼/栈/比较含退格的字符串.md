给定 `s` 和 `t` 两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回 `true`        `#` 代表退格字符。

注意：如果对空文本输入退格字符，文本继续为空。

示例 1：

```C++
输入：s = "ab#c", t = "ad#c"
输出：true
解释：s 和 t 都会变成 "ac"。
```

思路:依旧是用string模拟栈,用范围for查看字符串中是否有`#`,如果有那就删除ret的栈顶元素,没有就进栈

```C++
class Solution {
public:
    bool backspaceCompare(string s, string t)
    {
        string ret1;
        string ret2;
        for(auto c : s)
        {
            if(c != '#')
            ret1.push_back(c);
            else if(!ret1.empty() && c == '#')
            ret1.pop_back();
        }
        for(auto ch : t)
        {
            if(ch != '#')
            ret2.push_back(ch);
            else if(!ret2.empty() && ch == '#')
            ret2.pop_back();
        }
        return ret1 == ret2;
    }
};
```
