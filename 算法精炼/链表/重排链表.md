给定一个单链表 `L` 的头节点 `head`，单链表 `L` 表示为：

`L0 → L1 → … → Ln-1 → Ln`
请将其重新排列后变为：

`L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …`

不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

示例 1：

![1626420311-PkUiGI-image.png](images/1626420311-PkUiGI-image.png)

```C++
输入: head = [1,2,3,4]
输出: [1,4,2,3]
```

思路：先将该链表对半分→快慢双指针，再反转后半部分链表→头插法，再合并链表→双指针

注意：当使用头插法逆序的时候不管奇数还是偶数，统一断 `slow->next`，比如1→2→3→4，slow指向3，此时断3→4，分组成1→2→3和4,若是1→2→3→4→5,此时slow指向3，断3→4,变成1→2→3   4→5

```C++
class Solution {
public:
    void reorderList(ListNode* head)
    {
        //1.快慢指针找中点
        ListNode* slow = head,*fast = head;
        while(fast->next &&fast->next->next)
        {
            slow = slow->next;
            fast = fast->next->next;
        }
        //2.根据slow的位置分割，slow->next后面的为一组，前一组包括slow
        ListNode* head2 = new ListNode(0);//虚拟头节点
        ListNode* cur = slow->next;
        slow->next = nullptr;//断开连接
        //3.头插将后半部分逆序
        while(cur)
        {
            ListNode* next = cur->next;//保存节点方式首轮置空时丢失
            //先将cur所指的节点头插到虚拟头节点
            cur->next = head2->next;//第一轮相当于cur->next置空，让新链表的末尾指向空，形成一个合法的、有终点的链表。否则会指向2
            //本质就是让cur断开在原本链表中与2的连接，从而与虚拟头节点形成一个新的链表
            head2->next = cur;
            cur = next;//让next重新执行头插操作
        }
        //4.创建虚拟头节点用双指针合并两个链表
        ListNode* ret = new ListNode(0);//创建头节点存放结果链表(作用类似辅助数组)
        ListNode* prev = ret;
        ListNode* cur1 = head,*cur2 = head2->next;
        while(cur1)
        {
            //先放第一个链表
            prev->next = cur1;
            cur1 = cur1->next;
            prev = prev->next;
            //将第二个链表尾插
            if(cur2)
            {
                prev->next = cur2;
                cur2 = cur2->next;
                prev = prev->next;
            }
        }
    }
};
```
