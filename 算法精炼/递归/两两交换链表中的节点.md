给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

示例 1：

![swap_ex1.jpg](images/swap_ex1.jpg)

```C++
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

思路：依旧是先逆序后面的，最后返回原链表的尾指针(新链表的头指针），注意这里的重点是交换节点而非单纯逆转指针，注意看代码注释

```C++
class Solution {
public:
    ListNode* swapPairs(ListNode* head)
    {
        //出口
        if(head == nullptr || head->next == nullptr)
        return head;//结束去程递归
        //存第二个节点 交换后变新头
        ListNode* newhead = head->next;
        //不断深入递归直到head->next == nullptr开始回溯
        head->next = swapPairs(newhead->next);
        //回溯：开始执行交换节点，由于递归的返回机制，会自然结束返回链表，无需“停止条件”
        newhead->next = head;
        return newhead;//结束当前层回溯，进入下一层回溯
    }
};
```
