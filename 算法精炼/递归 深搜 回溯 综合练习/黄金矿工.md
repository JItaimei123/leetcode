你要开发一座金矿，地质勘测学家已经探明了这座金矿中的资源分布，并用大小为 `m * n` 的网格 `grid` 进行了标注。每个单元格中的整数就表示这一单元格中的黄金数量；如果该单元格是空的，那么就是 `0`。

为了使收益最大化，矿工需要按以下规则来开采黄金：

- 每当矿工进入一个单元，就会收集该单元格中的所有黄金。

- 矿工每次可以从当前位置向上下左右四个方向走。

- 每个单元格只能被开采（进入）一次。

- 不得开采（进入）黄金数目为 `0` 的单元格。

- 矿工可以从网格中 任意一个 有黄金的单元格出发或者是停止。

示例 1：

```C++
输入：grid = [[0,6,0],[5,8,7],[0,9,0]]
输出：24
解释：
[[0,6,0],
 [5,8,7],
 [0,9,0]]
一种收集最多黄金的路线是：9 -> 8 -> 7。
```

## 思路：

主函数用一个变量记录挖到的黄金的最大总数，然后通过递归不断累加两个数，直到越界或者找不到除了0之外的数

```C++
class Solution {
    int dir[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    int m,n;
public:
    int getMaximumGold(vector<vector<int>>& grid)
    {
        m = grid.size();
        n = grid[0].size();
        //记录能挖到黄金的最大总数
        int maxgold = 0;
        for(int i = 0;i<m;i++)
        {
            for(int j = 0;j<n;j++)
            {
                //只要这个格子有金子就可以作为起点
                if(grid[i][j] > 0)
                //从这里开始走记录最大值
                maxgold = max(maxgold,dfs(grid,i,j));
            }
        }
        return maxgold;
    }
    int dfs(vector<vector<int>>& grid,int i,int j)
    {
        //递归出口
        if(i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == 0) return 0;
        //记录当前格子的值，并且标记
        int currentgold = grid[i][j];
        grid[i][j] = 0;
        //往四个方向深搜，找出最大的和
        int maxnextgold = 0;
        for(int k = 0;k<4;k++)
        {
            int nx = i + dir[k][0];
            int ny = j + dir[k][1];
            //递归计算下一次能挖到多少，并记录值
            maxnextgold = max(maxnextgold,dfs(grid,nx,ny));
        }
        //回溯
        grid[i][j] = currentgold;
        return currentgold + maxnextgold;
    }
};
```

`return currentgold + maxnextgold;`实际上是传到了`maxgold = max(maxgold,dfs(grid,i,j));`，让当前的总和与之前的总和比较
