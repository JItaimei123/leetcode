给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

示例 1：

```C++
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

思路：分奇数与偶数的情况固定中点，奇数固定一个`(left = right)`，偶数固定两个`(right = left + 1`，不断向外扩散

```C++
class Solution {
public:
    string longestPalindrome(string s) 
    {
        //记录最长回文串的起始位置和长度
        int begin = 0,len = 0,n = s.size();
        for(int i = 0;i<n;i++)//遍历中点的位置
        {
            //先列举奇数的情况
            int left = i,right = i;
            while(left >= 0 && right <= n && s[left] == s[right])
            {
                left--;
                right++;
            }
            if(right - left - 1 > len)
            {
                begin = left + 1;
                len = right - left - 1;
            }
            //再列举偶数的情况
            left = i,right = i + 1;
            while(left >= 0 && right <= n && s[left] == s[right])
            {
                left--;
                right++;
            }
            if(right - left - 1 > len)
            {
                begin = left + 1;
                len = right - left - 1;
            }
        }
        return s.substr(begin,len)
    }
};
```
