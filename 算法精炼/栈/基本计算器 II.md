给你一个字符串表达式 `s`，请你实现一个基本计算器来计算并返回它的值。

整数除法仅保留整数部分。

你可以假设给定的表达式总是有效的。所有中间结果将在 `[-231, 231 - 1]` 的范围内。

注意：不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()`。

示例 1：

```C++
输入：s = "3+2*2"
输出：7
```

思路:建立一个`栈`和一个`char` 一个用于存放数字一个用于存放符号,将加减运算统一成加法运算,符号栈初始字符定义为`+`当遍历到减法后,直接将栈中的`+`换成`-`,当符号栈为`-`时,下一个遍历到的数取相反数,这样就可以统一成加法运算,遇到乘号,比如遇到`6*4`的时候,当遍历到时,直接替换`char`的符号,再把`6`从数字栈中取出 与下一个数先进行乘法运算,再放回数字栈,也就是放`24`回去,`/`同理,如果是`6*4/2`就把之前`6*4`算出放入数字栈的结果取出,与`2`进行除法运算,将结果再丢回数字栈.

### 总结：一切归为加法

> 所有运算最终都转化为“往栈里放一个带符号的数”，最后求和。

| 原始运算 | 转化后 |
| --- | --- |
| + num | 往栈里放 +num |
| - num | 往栈里放 -num |
| * num | 弹出栈顶，算出 栈顶 * num，放回去 |
| / num | 弹出栈顶，算出 栈顶 / num，放回去 |

最终栈里全是“待加项”，直接求和。

```C++
class Solution {
public:
    int calculate(string s) {
        // 1.前置工作
        int num = 0;    // 累计当前数字
        char op = '+';  // 符号初始化为+
        stack<int> stk; // 存待加项
        int ret = 0;    // 存放最终结果
        // 2.遍历一遍s,用c记录,如果是数字字符,那就累积成多位数
        for (int i = 0; i < s.size(); i++)
        {
            char c = s[i];
            // 3.如果是数字字符,那就累积成多位数
            if (isdigit(c))
                num = num * 10 + (c - '0');
            // 4.如果是运算符，或者到了末尾,那就要分类讨论是+-*/中的哪一种,从而对数字进行处理，分类写出处理结果
            if (!isdigit(c) && c != ' ' || i == s.size() - 1)
            {
                //'+'->数字直接入栈
                if (op == '+')
                    stk.push(num);
                //'-'->数字取相反数直接入栈
                else if (op == '-')
                    stk.push(-num);
                //'*'->取出栈顶元素与num相乘再入栈
                else if (op == '*')
                {
                    int top = stk.top();
                    stk.pop();
                    stk.push(top * num);
                }
                //'/'->取出栈顶元素与num相除再入栈
                else
                {
                    int top = stk.top();
                    stk.pop();
                    stk.push(top / num);
                }
                // 更新运算符
                op = c;
                // 清空数字
                num = 0;
            }
        }
        // 5.栈内求和
        while (!stk.empty())
        {
            ret += stk.top();
            stk.pop();
        }
        return ret;
    }
};
```
