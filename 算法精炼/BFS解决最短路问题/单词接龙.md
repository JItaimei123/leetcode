字典 `wordList` 中从单词 `beginWord` 到 `endWord` 的 转换序列 是一个按下述规格形成的序列 `beginWord -> s1 -> s2 -> ... -> sk`：

- 每一对相邻的单词只差一个字母。

- 对于 `1 <= i <= k` 时，每个 `si` 都在 `wordList` 中。注意， `beginWord` 不需要在 `wordList` 中。

- `sk == endWord`

给你两个单词 `beginWord` 和 `endWord` 和一个字典 `wordList`，返回 *从 `beginWord` 到 `endWord` 的 最短转换序列 中的 单词数目*。如果不存在这样的转换序列，返回 `0`。

示例 1：

```C++
输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出：5
解释：一个最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog", 返回它的长度 5。
```

思路与[最小基因变化](https://leetcode.cn/problems/minimum-genetic-mutation/)基本一样。

```C++
class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList)
    {
        //将有效转换存到哈希表
        unordered_set<string> hash(wordList.begin(),wordList.end());
        if(beginWord == endWord) return 1;
        if(!hash.count(endWord)) return 0;
        //bfs
        queue<string> q;
        q.push(beginWord);
        hash.erase(beginWord);
        int steps = 1;
        while(!q.empty())
        {
            int sz = q.size();
            steps++;
            for(int i = 0;i<sz;i++)
            {
                //获取队头数据
                string curword = q.front();
                q.pop();
                //尝试修改每一位
                for(int j = 0;j<curword.size();j++)
                {
                    //记录每一位的原始字母
                    char oriword = curword[j];
                    //将每一位尝试修改成a~z
                    for(char w = 'a' ; w <= 'z' ;w++)
                    {
                        if(w == oriword) continue;
                        curword[j] = w;
                        //如果在哈希表中
                        if(hash.count(curword))
                        {
                            //符合目标单词
                            if(curword == endWord) return steps;
                            //不符合目标单词 存入队列并从哈希表中删除(标记已用)等下次处理
                            hash.erase(curword);
                            q.push(curword);
                        }
                    }
                    curword[j] = oriword;
                }
            }
        }
        return 0;
    }
};
```
