给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

示例 1：

```C++
输入:a = "11", b = "1"
输出："100"
```

思路：模拟进位过程，用carry记录进位，注意这里是要把字符`'0'`和`'1'`变成数字`0 1`参与加法计算，所以要用`-'0'`，用`sum`记录当前位的总和，`res`记录每一位相加的结果

### 核心区分

| 操作 | 方向 | 例子 |
| --- | --- | --- |
| - '0' | 字符 → 数字 | '1' - '0' = 1 |
| + '0' | 数字 → 字符 | 1 + '0' = '1' |

```C++
class Solution {
public:
    string addBinary(string a, string b) 
    {
        string res;//用于存放结果
        int carry = 0;//记录进位
        int cur1 = a.size()-1,cur2 = b.size()-1;
        while(cur1 >= 0 || cur2 >= 0 || carry)
        {
            int sum = carry;//当前位的总和
            if(cur1 >= 0) sum += a[cur1--] - '0';//转换为数字进行加法运算
            if(cur2 >= 0) sum += b[cur2--] - '0';
            res += (sum % 2) + '0';//每一位加起来的总和，转换回字符存储
            carry = sum / 2;//更新进位
        }
        reverse(res.begin(),res.end());
        return res;
    }
};
```

注意：`int cur1 = a.size()-1`这个写法既可以代表`长度`也可以代表`指针所指的地方`，具体看后面怎么用
